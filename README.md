# Thesis Human Benchmark 2024

Archival human/expert benchmark for the 575 FY2024 firms in the V4.3 thesis.

This repository is intentionally separate from the frozen thesis reproduction kit. It stores the post-main-study evidence collection requested after the advisor meeting: public 2024 human/expert reports, their provenance, and frozen mappings into the V4.3 nine-action space.

## Current status

- First-pass public-web discovery: **575 / 575 complete**
- Reviewed mapping records: **292 / 575**
- Current strict one-action archival subset: **9 firms**
- Follow-up queue for primary-text / second-pass review: **52 firms**

## Current source of truth

Use `data/firm_level_benchmark.csv` for the audited one-row-per-firm state and `outputs/strict_archival_benchmark.csv` for the strict subset. Historical batch files and audit files are retained as provenance. `data/benchmark_master_575.csv` and `data/canonical_shard_*.csv` are reconciled to that audited state.
